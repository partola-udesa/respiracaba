# Exploración de estilo: mapa protagonista + vidrio + modo oscuro

Prototipo de UNA pantalla (resultado de ruta) para decidir la dirección visual antes de rediseñar en Figma.

- Abrir `pantalla_ruta_estilo_oscuro.html` en Chrome. Tocar la rayita de la hoja inferior para ver el detalle.
- Referencias: interfaces de running y mapas con el mapa a pantalla completa, hojas inferiores de vidrio y un número grande como protagonista.
- El mapa está dibujado con datos del repo: red peatonal y vías principales de OSM, espacios verdes del GCBA (zona Palermo / Lagos).
- La ruta se calculó sobre la red peatonal, priorizando senderos de parque y penalizando avenidas.
- **Datos reales:** distancia, % del recorrido dentro de espacios verdes y cantidad de avenidas cruzadas.
- **Ilustrativo:** el valor del índice (82 %), sus componentes y el texto de la IA (el índice todavía no está calculado).
